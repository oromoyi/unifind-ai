# Testing methodology and actual results

## 1. Strategy
* **Backend:** pytest with Flask's test client and in-memory SQLite (isolated per test). The same code was also exercised manually against MariaDB 10.11 (schema load, full seed, live API smoke test of login, search, matches, analytics and CSV export).
* **Frontend:** Vitest + Testing Library component tests (6) and a production build (`npm run build`). Pages were also opened with a headless Chromium session against the live API: no console errors were recorded on the landing, browse, student, matches, admin dashboard, analytics and manage pages.
* **Not performed:** load/performance testing, penetration testing by a third party, cross-browser matrix, screen-reader audit, live SMTP test, Docker build.

## 2. How to run
```powershell
cd backend; python -m pytest -v
cd ..\frontend; npm test; npm run build
```

## 5. Matching evaluation (computed, synthetic benchmark)
Dataset: `backend/evaluation/dataset.json` — **synthetic**, generated by `generate_dataset.py` (seed 42): 60 lost reports, 110 found items, one true counterpart each, 50 distractors including hard negatives. Weights: defaults (image signal unused, no photos). Results below are produced by `app.evaluation.run_evaluation` and also visible live on the admin *Analytics & research* page.

| Metric | Keyword baseline | Weighted matcher |
|---|---|---|
| Precision@1 | 0.633 | 0.933 |
| Hit-rate@3 | 0.767 | 0.983 |
| Hit-rate@5 | 0.833 | 1.0 |
| MRR | 0.722 | 0.96 |

Matcher precision/recall by score threshold (all 60×110 pairs):

| Threshold | Precision | Recall | F1 |
|---|---|---|---|
| 30 | 0.136 | 1.0 | 0.24 |
| 40 | 0.284 | 1.0 | 0.443 |
| 50 | 0.594 | 0.95 | 0.731 |
| 60 | 0.961 | 0.817 | 0.883 |
| 70 | 1.0 | 0.417 | 0.588 |

**Interpretation and caveats (state these when presenting):** the matcher outperforms the baseline on this benchmark, but (a) the data are generated from templates by the same author as the matcher, so results are optimistic; (b) the baseline cannot use category, place or date, so the comparison measures the value of metadata as much as of weighting; (c) no confidence intervals are reported; (d) there are no real-user or survey results in this project. Use the numbers to illustrate the method and to choose a default notify threshold (≈60 balances precision and recall *on this benchmark*), then re-evaluate on real labelled data.
